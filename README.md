# NeuroVibe WebXR - Clinical Command Center

Sistema de rehabilitación vestibular adaptativa mediante telemetría biométrica en tiempo real y retroalimentación háptica en entornos WebXR.

## 🚀 Características
- **Motor 3D WebXR:** Construido con Three.js para renderizado dinámico en navegador.
- **Telemetría en Tiempo Real:** Comunicación bi-direccional usando WebSockets (Socket.IO).
- **Prevención de Cibermareo:** Adaptación automática de estímulos según la carga cognitiva del paciente.
- **Dashboard Futurista:** Métricas biométricas en vivo, gráficas dinámicas y consola de simulación de pruebas.

## 🛠️ Tecnologías Utilizadas
- **Backend:** Node.js, Express, Socket.IO
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Three.js, Chart.js
